# Delphi 12 + PostgreSQL Analytics Dashboard

## Фичи
- Многопоточная загрузка данных через FireDAC с пулингом соединений
- Асинхронное обновление UI без блокировок
- Виртуальное дерево (VirtualStringTree) для отображения 1000+ записей
- PostgreSQL: JSONB, полнотекстовый поиск, оконные функции (готовность к Sprint 2)
- Интеграция семафора для защиты пула соединений при числе исчерпания пула

## Запуск
1. Выполнить `SQL/Change/001_schema.sql` и `SQL/Source/002_seed.sql`
2. Открыть `Source/pgDelphi.dproj` в Delphi 12
3. Скомпилировать и запустить

## Технологии
- Delphi 12, FireDAC, VirtualStringTree, DevExpress ExpressBars
- PostgreSQL 15+, GIN-индексы, TSVECTOR
- Semaphore protection с соединениями

## 🔁 Real-time обновления (Sprint 2)

Приложение использует **Smart Polling (Delta Sync)** для мгновенного отображения новых событий:

### Как это работает
1. Фоновый поток `TRealTimePoller` раз в 1 сек проверяет `MAX(id)` в таблице `events`
2. Если обнаружены новые записи (`id > last_max`), выполняется выборка только дельты
3. Данные передаются в UI через `TThread.Queue` и добавляются в `VirtualStringTree`

### Преимущества подхода
- ✅ Нулевая нагрузка на сервер при отсутствии новых данных
- ✅ Автоматическое восстановление при обрыве соединения (`AutoReconnect`)
- ✅ Полная совместимость с пулингом FireDAC
- ✅ Потокобезопасность без блокировок

### Настройка
- Интервал опроса: `1000 мс` (можно изменить в `RealTimePoller.Create`)
- Таймаут реконнекта: `3000 мс` при ошибке
