# CalcPriceTests — Модульные тесты расчета цен

Этот каталог содержит набор модульных тестов на базе **DUnitX** для проверки корректности работы модуля расчета цен с НДС (`uCalcPricesProc.pas`), расположенного в `..\..\CalcPriceDLL\`.

## 🎯 Назначение

Тестирование чистой бизнес-логики (без зависимостей от VCL/UI) для гарантии корректного математического и бухгалтерского округления цен при расчете стоимости с НДС и без НДС.

## 🧪 Что тестируется

### 1. Функция `CheckNum`
Проверяет, что число имеет не более двух знаков после запятой (корректное денежное представление), устойчиво к артефактам плавающей точки (`double`).
- Тесты на целые числа, 1 и 2 знака после запятой (ожидается `True`).
- Тесты на 3 и более знаков после запятой (ожидается `False`).
- Тесты на типичные денежные суммы (round-trip валидация).

### 2. Процедура `CalcPricesProc`
Проверяет алгоритм подбора корректных пар цен (с НДС и без НДС), которые при обратном пересчете дают исходную сумму с учетом бухгалтерского округления.
- **NDS 0%**: Входная цена равна выходной.
- **NDS 20% и 10%**: Проверка целых и дробных значений, включая обратную совместимость (round-trip: `Цена_без_НДС * Коэффициент ≈ Цена_с_НДС` с допуском `0.01`).
- **Граничные случаи**: Нулевая цена (`0.00`), минимальная цена (`0.01`), большие суммы (`1_200_000.00`), дробные входные значения (`118.99`, `999.99`).

## 🚀 Как запустить тесты

### Вариант 1: Из Delphi IDE
1. Откройте `CalcPriceFixture.dproj` в Delphi.
2. Выберите конфигурацию `Debug` или `Release`.
3. Нажмите `Run` (F9). Результаты отобразятся в консоли и будут сохранены в XML.

### Вариант 2: Из командной строки (MSBuild)
```cmd
cd c:\Users\Alexandr\Documents\forAI\loader\loader\DUnitXTests\CalcPriceTests
msbuild CalcPriceFixture.dproj /p:Config=Debug /t:Build
.\exe\CalcPriceFixture.exe
```
